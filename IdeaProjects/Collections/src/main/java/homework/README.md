## Выводы

ArrayList быстрее при доступе по индексу благодаря O(1) и обычно быстрее
при добавлении в конец. LinkedList эффективнее при добавлении и удалении
элементов в начале, так как не требует сдвига элементов.

При вставке в середину обе коллекции имеют сложность O(n): ArrayList
сдвигает элементы, а LinkedList ищет нужную позицию. ArrayList также
выигрывает за счёт лучшей локальности данных в памяти.

Таким образом, выбор коллекции зависит от характера операций: ArrayList
подходит для частого доступа по индексу, а LinkedList — для частых
изменений в начале списка.
